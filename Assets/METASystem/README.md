# Cloud Hop：马卡龙云朵与空中操控

`PlatformerLevel` 保留起始约 50 米的固定路线，随后沿 Z 轴进入无限随机路线。随机台阶是有厚度的不规则五边形，路线会轻微左右摆动；玩家脚下设有安全底地面，落到安全底面不会失败。每段地面有缓慢扩张、收缩并迁移的岩浆洞，开口网格和碰撞会同步更新，地面安全区域始终高于 70%。洞沿会提前发光预警。

生成器默认每段 32 米、前方保持 3 段。最近踩过的台阶作为检查点；岩浆洞触发后回到该台阶并清除暂存移动效果，路线进度与云朵体验历史保留。HUD 显示当前距离和跨场次保存的最远距离。离开此关卡仍使用现有 Return to Hub 门。

打开 `Assets/Scenes/PlatformerLevel.unity` 并进入 Play 模式。前、中、后三个 `FloatArea_*` 区域各最多 8 朵云；空间不足时允许少于 8 朵，不设数量下限。尺寸、形态与颜色配额同时统计已生成云朵及等待生成的预留项。

补充失败时保留已选尺寸、形态和属性，每次最多尝试 30 个位置，稍后重试。消耗后先等待 2 秒开始补充，再寻找新位置 10 秒，之后才允许复用旧位置；旧位置仍必须通过完整的空间检查。`Previous Position Reuse Delay` 可在 Inspector 调整这 10 秒等待时间。

| 颜色 | 属性 | 玩家可以决定的事 |
| --- | --- | --- |
| 蜜桃粉 Peach | Updraft：向上弹射 | 用移动输入选择少量水平位移方向 |
| 奶油蓝 Blue | Slingshot：定向弹射 | 按移动输入方向发射，无输入时按视线水平方向 |
| 薰衣草紫 Lilac | Feather：低重力，制止快速下坠 | 在 4–6 秒内转向、缓降、寻找落点 |
| 薄荷绿 Mint | Lift：制止下坠后缓慢上浮 | 在 3–4 秒内选择下一朵云或平台 |

**颜色在生成时确定，触碰时不会重新抽属性。** 玩家可以主动连续选择同一种颜色。
原先按触碰顺序强制防重复的规则改为区域内种类配额与邻近间距，避免破坏玩家选择。
每朵云都恢复一次空中冲刺；只有力度与持续时间在较小范围内随机。

## 操作

- WASD / 左摇杆：移动，并控制触碰云朵时的发射方向；空中还能修正弹射动量。
- SPACE / A：跳跃；下落时长按缓降，默认最大下坠速度 3 米/秒。
- SHIFT / L3：冲刺，可制止下坠并替换残留的水平弹射动量。落地或碰云恢复一次。
- E / Y：空中刹车，快速消除水平速度；松开继续操控。
- 冲刺、墙跑、墙跳继续保留。浮力会脱离墙面，弹射打断正在进行的冲刺或墙跑。

英文 HUD 四周显示颜色图例、实际水平/垂直速度、脚底到下方表面的距离、熔岩提示、当前效果与倒计时、冲刺次数、本次存活时间和本次碰云数量。
没有下方表面时距离显示 `--`，不会误报为零；熔岩触发器纳入探测，云朵触发器不计入地面。
HUD 不接收鼠标点击，保留中央视野。

## 外观与配置

云朵主体是程序生成的圆润多团网格，使用柔和卡通着色器。凸包触发器只负责接触判定，不是可站立平台。
Particle System 负责低密度飘散小云团与触碰爆散，不承担主体或碰撞。每朵最多 24 个粒子；回收后清空，复用时重新着色。
Each cloud ranges from 0.9 m to 6.3 m: the smallest stays the same and the largest is 3× the previous maximum. Large clouds spawn higher to preserve ground clearance.

- 选中 `FloatArea_*`，用 `Size` 与位置调整区域，`Platform Root` 指向 `Platforms`。建议区域 Transform 缩放保持 `(1,1,1)`。
- `Target Count`、`Replenish Delay`、`Diameter Range`、`Height Above Platform` 控制密度与尺寸；空间不足会延后补充。
- `Effects` 控制弹射速度、重力倍率、上浮加速度与持续时间。新重力效果替换旧效果。
- 玩家 `PlayerMovement` 中的 `Air Acceleration`、`Air Turn Degrees`、`Air Brake Deceleration`、`Glide Fall Speed` 调整操控力度。
- `CloudStyle` 是世界颜色、粒子颜色和 HUD 图例的唯一配色来源。`CloudToon.shader` 决定主体柔和明暗。
- 区域种子控制外观、位置、属性；玩家种子控制具体效果数值。相同调用顺序可复现随机结果，玩家路线和消耗时刻会影响后续生成。

## 验证

Unity Test Runner 中运行 EditMode 的 `FloatRandomTests` 和 PlayMode 的 `FloatSystemTests`。
测试涵盖配额与固定种子、颜色/属性一致性、输入决定方向、冲刺恢复、缓降/刹车/转向、HUD 离地与熔岩探测、效果替换和到期、撞顶、重生、墙跳以及对象池补充。
最终手感仍需实际游玩；这些救险能力增加了操作空间，但不会自动保证安全落地。
